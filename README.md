# Sloth Pet

跨平台 3D AI 桌宠：透明置顶窗口中的 VRM 角色，支持 AI 对话（文字/语音）、框选截屏分析、定时提醒、自主行为动画。

技术栈：Tauri 2 + React + Three.js（@pixiv/three-vrm）+ Rust。

## 功能一览

- **AI 对话**：流式回复，情绪驱动表情与动作（开心蹦跳、难过摇头等）
- **语音**：麦克风语音输入（ASR）+ 扬声器语音播报（TTS，音色可配）
- **截屏分析**：全局快捷键框选区域（macOS 原生十字选框），或托盘菜单全屏截图，视觉模型解读
- **定时提醒**：一次性 / 每天 / 每周 / 时段间隔（如每天 09:00–18:00 每小时一次）；到点窗口放大 + 宠物持续敲屏 + 气泡提醒
- **自主行为**：待机呼吸、眨眼、视线追踪光标、闲置时东张西望、随机小动作（伸懒腰/打瞌睡/打哈欠等）
- **互动**：拖动移动窗口、双击随机动作、悬停出现聊天入口

## 快速开始

```bash
npm install
npm run tauri dev
```

首次使用：托盘图标 → **⚙️ 设置** → **大模型** → 选服务商、填 API Key、选模型 → 保存。

## 使用说明

### 交互方式

| 操作 | 效果 |
|------|------|
| 按住拖动 | 移动窗口 |
| 鼠标悬停 | 右上角出现 💬，点击打开聊天面板（窗口自动右扩，左宠物右对话） |
| 双击角色 | 随机播放一个启用的动作 |
| 托盘菜单 | 聊天 / 截屏分析（全屏）/ 设置 / 退出 |
| 全局快捷键 | 框选区域截图分析（默认 `command + shift + p`，可自定义，Esc 取消） |
| 🎤 按钮（左下角） | 语音输入：点击开始录音，再点停止并识别发送（需在设置开启） |

### 设置（托盘 → ⚙️ 设置）

- **大模型**：服务商（DeepSeek / 百炼 / 智谱 / Kimi / 豆包 / 混元 / 千帆 / MiniMax / 阶跃 / 硅基流动 / Ollama 本地 / 自定义 OpenAI 兼容端点）、API Key（仅存系统钥匙串，不落明文）、对话模型、视觉模型
- **性格设定**：慵懒 / 工作 / 娱乐三种预设模式 + 自定义模式（直接改文案）
- **语音设置**：语音输入、语音播报独立开关。语音输入把录音直接发给对话模型理解并回复（复用对话服务商和主 Key，需模型支持音频输入，如百炼 qwen3-omni-flash）；语音播报走 OpenAI 兼容 `/audio/speech`，Base URL / API Key 留空则复用对话服务商，合成模型（默认 tts-1）、音色（alloy/nova 或百炼 Cherry/Ethan 等，可自填）
- **提醒**：一次性 / 每天 / 每周 / 时段间隔；可启停、删除
- **模型与动作**：自定义 VRM 模型 + 动作开关列表（详见下节）
- **软件设置**：截图快捷键（聚焦输入框后按组合键录入，Backspace 清除）

### 自定义模型与动作

模型格式必须是 **VRM**（`.vrm` 文件）：

1. 设置 → **模型与动作** → **打开模型目录**
2. 把你的 `.vrm` 重命名为 **`custom.vrm`** 放进该目录
   （`~/Library/Application Support/com.slothpet.desktop/models/`，Windows 为 `%APPDATA%/com.slothpet.desktop/models/`）
3. 点 **重新加载** 生效；删除该文件恢复默认模型
4. 换模型后点 **🔄 同步动作**：自动探测新模型支持的动作（骨骼/表情/动画片段），不支持的置灰

动作开关：挥手 / 点头 / 摇头 / 蹦跳 / 前空翻 / 打瞌睡 / 敲屏幕 / 手工片段（伸懒腰、兴奋摇摆、思考挠头）/ 打哈欠。双击随机、自主行为、情绪联动都只从勾选池里挑。

**哪里获得 VRM 模型**：

- **VRoid Studio**（Steam 免费下载，国内可用）：自己捏人导出 `.vrm`，最推荐
- **VRoid Hub / Booth**：现成模型，注意授权（禁止二次配布的模型可以本机自用，但不要提交进仓库或随软件分发）
- 注意：AI 生成不了带骨骼绑定的 VRM；MMD 的 PMX 格式需要转换工具

## 权限说明（macOS）

- **屏幕录制**（截屏分析）：首次截图会弹授权；授权后需完全退出应用重开。dev 模式下权限记在启动它的终端应用上（Terminal/iTerm 等），换启动方需各自授权；打包安装的 `.app` 权限稳定
- **麦克风**（语音输入）：首次录音弹授权，允许即可

## 打包（macOS）

```bash
npx tauri build --bundles app        # 产出 .app
npx tauri build --bundles app,dmg    # 加 DMG 安装镜像
```

## 常见问题

- **快捷键没反应**：确认没被其他应用占用（如 VS Code 的 `Cmd+Shift+P`）；设置页录入后保存即生效
- **截图只截到桌面壁纸**：屏幕录制权限没授予，或未重启应用
- **语音没声音**：检查设置 → 语音设置里合成模型和音色是否与服务商匹配（DeepSeek 无语音接口，需填 OpenAI/硅基流动等的 Base URL，Key 复用主 Key）
