# Sloth Pet

跨平台 3D AI 桌宠：透明置顶窗口中的 VRM 角色，支持 AI 对话（文字/语音）、框选截屏分析、定时提醒、自主行为动画与模型/动作工坊。

技术栈：Tauri 2 + React + Three.js（@pixiv/three-vrm）+ Rust。

## 下载安装

到 [Releases](https://github.com/wuyewen/sloth-pet/releases) 下载最新安装包：

- **macOS Apple 芯片**：`*_aarch64.dmg`；**macOS Intel**：`*_x64.dmg`
- **Windows**：`.msi` 安装包

macOS 首次打开如提示「无法验证开发者」：右键 → 打开即可（未公证应用的正常提示）。

首次使用：托盘图标 → **⚙️ 设置** → **大模型** → 选服务商、填 API Key、选模型 → 保存。API Key 只存系统钥匙串，不落明文文件。

## 功能一览

- **AI 对话**：流式回复，情绪驱动表情与动作（开心蹦跳、难过摇头等，情绪→动作的映射可自定义）
- **语音**：麦克风语音输入（ASR）+ 扬声器语音播报（TTS，音色可配，播报时角色口型同步开合）
- **截屏分析**：全局快捷键框选区域（macOS 原生十字选框），或托盘菜单全屏截图，视觉模型解读
- **定时提醒**：一次性 / 每天 / 每周 / 时段间隔（如每天 09:00–18:00 每小时一次）；到点窗口放大 + 宠物持续敲屏 + 气泡提醒
- **自主行为**：待机呼吸、眨眼、头部微倾、微表情、扫视式视线追踪、闲置时东张西望、随机小动作（伸懒腰/打瞌睡/打哈欠等）
- **互动**：拖动移动窗口、双击随机动作、悬停引起注意、光标摸头、单击戳一戳
- **模型与动作工坊**：多模型库管理、任意 `.vrma` 动作导入、动作试播预览、舞蹈完整播放

## 使用说明

### 交互方式

| 操作 | 效果 |
|------|------|
| 按住拖动 | 移动窗口 |
| 鼠标悬停 | 右上角出现 💬，点击打开聊天面板；停留片刻宠物会看向光标并倾身 |
| 光标在头部区域来回移动 | 摸头：宠物开心 + 蹦跳（有冷却） |
| 单击角色 | 戳一戳：惊讶 + 点头（与双击自动区分） |
| 双击角色 | 随机播放一个启用的短动作 |
| 托盘菜单 | 聊天 / 截屏分析（全屏）/ 设置 / 退出 |
| 全局快捷键 | 框选区域截图分析（默认 `command + shift + p`，可自定义，Esc 取消） |
| 🎤 按钮（左上角） | 语音输入：点击开始录音，再点停止并识别发送（需在设置开启） |

### 设置（托盘 → ⚙️ 设置）

- **大模型**：服务商（DeepSeek / 百炼 / 智谱 / Kimi / 豆包 / 混元 / 千帆 / MiniMax / 阶跃 / 硅基流动 / Ollama 本地 / 自定义 OpenAI 兼容端点）、API Key（仅存系统钥匙串）、对话模型、视觉模型
- **性格设定**：内置慵懒 / 工作 / 娱乐三种模式，模式的名称和文案都可编辑，可新建/删除（至少保留一个），单选生效
- **语音设置**：语音输入、语音播报独立开关；播报支持百炼 / OpenAI 兼容 / 硅基流动等，音色可选
- **提醒**：一次性 / 每天 / 每周 / 时段间隔；可启停、删除
- **模型与动作**：模型库 + 动作工坊（详见下节）
- **软件设置**：截图快捷键（聚焦输入框后按组合键录入，Backspace 清除）

### 模型库与动作工坊

模型格式为 **VRM**（`.vrm`），动作为 **VRMA**（`.vrma`），VRM 0.x 与 1.0 均支持（0.x 模型自动转正朝向）：

1. 设置 → **模型与动作**：默认目录为应用数据目录（macOS `~/Library/Application Support/com.slothpet.desktop/models/`，Windows `%APPDATA%/com.slothpet.desktop/models/`），也可点 **选择目录** 换成任意自定义目录（模型与动作一起搬走，恢复默认一键切回）
2. `.vrm` 文件放进目录根部（**任意文件名**，可放多个）；`.vrma` 动作文件放进 `motions/` 子目录
3. 点 **重新加载** / **同步动作**，然后：
   - 模型列表中单选切换当前模型
   - 动作列表中勾选启用，每个动作可点 **试播** 立即演示
   - 动作可改显示名；时长 >8s 的自动标记为「舞蹈」（完整播放、不进随机池），也可手动标记
   - 「情绪联动」区可为开心/惊讶/难过/生气分别指定配套动作

双击随机、自主行为、情绪联动都只从勾选池里挑；舞蹈类长动作只通过试播播放。

## 模型与动作从哪来

先看来源和格式，再点下载：来源清楚、格式是 `.vrm`、授权允许个人使用，比收藏一堆"看起来很厉害"的链接重要得多。

| 渠道 | 适合谁 | 怎么用 |
|------|--------|--------|
| **[VRoid Hub](https://hub.vroid.com)** | 想找原创 VRM 角色 | 最大 VRM 社区，标签筛选，注意看角色页的下载开关与使用条件 |
| **[模之屋](https://www.aplaybox.com)** | 中文用户、找熟悉的 IP/角色 | 中文搜索方便，务必筛选 `.vrm` 格式（大量资源是 PMX/MMD） |
| **[BOOTH](https://booth.pm)** | 高质量免费/付费资源 | 搜「VRM」「VRMA」「VRM モーション」，动作包主要在这里 |
| **[VRoid Studio](https://vroid.com/studio)** | 找不到现成的就自己捏 | 免费捏人软件，无需建模基础，直接导出 `.vrm` |

动作文件（`.vrma`）主要来自 BOOTH 的 VRMA 动作包和 VRoid Hub 的动作分区；同一个动作文件任何 VRM 模型都能播。**建议优先收 VRMA**——MMD 的 `.vmd` 动作虽然网上存量更大，但需要转换且按 MMD 模型比例制作，穿模概率高，除非遇到非它不可的动作。

**格式对照**：

| 格式 | 能否直接用 | 说明 |
|------|-----------|------|
| `.vrm` / `.vrma` | ✅ 直接导入 | 首选，动作文件推荐只收这个格式 |
| `.vmd` | ⚠️ 需转换 | MMD 动作格式（网上存量最大的舞蹈资源），需用 Blender + mmd_tools 转为 VRMA |
| `.pmx` / `.pmd` / `.fbx` | ⚠️ 需转换 | 用 Blender + VRM Addon 转换为 VRM |
| `.vroid` | ⚠️ 需导出 | VRoid Studio 工程文件，在 VRoid Studio 里导出 `.vrm` |

**授权提醒**：下载前确认格式、来源和授权条款（个人使用/录屏/再配布是不同层级）。标注「禁止再配布」「配布終了」的资源请尊重作者意愿；下载的模型**可以本机自用，但不要提交进本仓库或随软件分发**。本应用内置模型为原创资产，随仓库以相同许可证发布。

## 权限说明（macOS）

- **屏幕录制**（截屏分析）：首次截图会弹授权；授权后需完全退出应用重开。dev 模式下权限记在启动它的终端应用上（Terminal/iTerm 等），换启动方需各自授权；打包安装的 `.app` 权限稳定
- **麦克风**（语音输入）：首次录音弹授权，允许即可
- **钥匙串**（API Key 存储）：未签名应用更新版本后，macOS 会重新弹钥匙串授权，点允许即可；若 Key 失效，在设置页重新填一次保存

## 打包（macOS）

```bash
npx tauri build --bundles app        # 产出 .app
npx tauri build --bundles app,dmg    # 加 DMG 安装镜像
```

仓库带 GitHub Actions 发版流（`.github/workflows/release.yml`）：推送 `v*` 标签自动构建 macOS（aarch64 + x64）和 Windows 安装包并发布到 Releases，版本号自动取 tag。

```bash
git tag v1.0.1 && git push origin v1.0.1
```

## 常见问题

- **快捷键没反应**：确认没被其他应用占用（如 VS Code 的 `Cmd+Shift+P`）；设置页录入后保存即生效
- **截图只截到桌面壁纸**：屏幕录制权限没授予，或未重启应用
- **语音没声音**：检查设置 → 语音设置里合成模型和音色是否与服务商匹配（DeepSeek 无语音接口，需填 OpenAI/硅基流动等的 Base URL，Key 复用主 Key）
- **下载的模型背对镜头**：VRM 0.x 模型会自动转正，无需操作
- **macOS 提示「无法验证开发者」**：未签名应用的正常提示，右键 → 打开
